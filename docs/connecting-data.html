Connecting Data

PersonalOS is only as useful as the data it can see. Connect your sources in minutes.

Available integrations

/skill load google-workspace     # Gmail + Calendar + Drive
/skill load github               # Code repositories
/skill load telegram             # Already done in setup
/skill load browser-automation   # Any website without an API

Google Workspace

Run /skill load google-workspace in Telegram or terminal. You'll be prompted to authenticate via OAuth. Once connected, all agents can read Gmail, Calendar, and Drive.

GitHub

Create a personal access token with repo scope, then:

export GITHUB_TOKEN=your_token_here
/skill load github

Browser Automation

For services without an API — POS systems, custom dashboards, legacy tools — the browser automation skill can read and interact with any web interface.

/skill load browser-automation
# Then describe what you need:
"Read today's sales from my POS dashboard at https://..."
