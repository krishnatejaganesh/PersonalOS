Telegram Setup

How to create your bot, get your credentials, and connect PersonalOS — step by step.

Why Telegram?

Telegram is how PersonalOS talks to you — morning briefings, task results, alerts, and your commands all flow through it. The bot API is free, works on every device, and gives you instant push notifications.

Step 1 — Create your bot

1

Open BotFather

In Telegram, search for @BotFather (look for the blue verified checkmark). Tap Start.

2

Create the bot

Send /newbot. BotFather will ask for two things:

  • Display name — what appears in the chat header (e.g. My PersonalOS)
  • Username — must be unique and end in bot (e.g. mypersonalos_bot)
3

Copy your token

BotFather replies with your API token:

Done! Use this token to access the HTTP API:

7123456789:AAF_abc123XYZexampleTokenHere

Copy the token. You'll paste it into the setup wizard.

Keep this token private — anyone with it can send messages as your bot.

Step 2 — Get your user ID

4

Message @userinfobot

Search for @userinfobot and tap Start. It replies immediately:

Id: 123456789
First: Krishna
Last: Teja
Username: @krishnateja

Copy the number next to Id: — that's your Telegram user ID. PersonalOS uses it to only respond to you.

Step 3 — Lock down your bot (recommended)

By default your bot is publicly findable. Two quick settings in BotFather to tighten this:

5

Disable group chats

Send /mybots to BotFather → select your bot → Bot Settings → Allow Groups? → Turn off.

Your bot is personal — it shouldn't be addable to group chats.

Step 4 — Enter credentials during setup

When you run ./scripts/setup.sh, it asks:

Telegram bot token: 7123456789:AAF_abc123...
Your Telegram user ID: 123456789

Paste them in. The script writes them to your .env file automatically.

If you've already run setup and need to update them, open .env and edit:

TELEGRAM_BOT_TOKEN=7123456789:AAF_abc123...
TELEGRAM_USER_ID=123456789

Then restart:

docker compose restart api

Step 5 — Test the connection

Find your bot in Telegram (search by its username) and send:

Hello

It should reply within a few seconds. If it doesn't, check the logs:

docker compose logs api --tail=50

Talking to PersonalOS

Once connected, everything is plain English:

What should I focus on today?
Run the morning briefing now
@developer fix the login bug on the checkout page
Read my last 5 emails and flag anything urgent

Common issues

Bot doesn't respond at all

Check the bot token is correct in .env and that the API container is running:

docker compose ps
docker compose logs api --tail=50

"Unauthorized" in the logs

Your bot token is wrong or was regenerated. Get a new one from BotFather: send /mybots → select your bot → API Token → Revoke current token. Update TELEGRAM_BOT_TOKEN in .env, then run docker compose restart api.

Bot responds to other people

Your TELEGRAM_USER_ID in .env is wrong or missing. Get it from @userinfobot, update .env, and restart.

Messages are very slow

PersonalOS polls Telegram by default. If you're on a VPS with a public IP you can switch to webhooks for instant delivery — see the Connecting Data guide.

Multiple devices

Telegram syncs across all your devices automatically. Your bot messages appear on your phone, desktop, and web — no extra setup needed.
