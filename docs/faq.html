Frequently Asked Questions

Everything people ask before deploying PersonalOS.

General
What exactly is PersonalOS?

PersonalOS is an open-source AI operating system you deploy on your own server. It gives you a team of specialised AI agents (Chief of Staff, Developer, SEO, Researcher, Support) backed by a persistent memory layer — all running on models you choose.

Think of it as your own private AI infrastructure, not a SaaS product someone else controls.

How is this different from just using ChatGPT or Claude?

ChatGPT and Claude start fresh every conversation. PersonalOS has persistent memory — it remembers your projects, preferences, workflows, and what worked last time.

It also runs multiple specialised agents on a schedule (morning briefings, automatic task routing, weekly reviews) rather than waiting for you to open a tab and type a prompt.

Do I need to know how to code?

Basic terminal comfort is enough to get started. The setup script handles installation and configuration with a guided wizard. Most day-to-day use is through Telegram — no terminal needed.

If you want to build custom agents or integrations, Python knowledge helps but isn't required for the pre-built personas.

Is PersonalOS affiliated with Anthropic, OpenAI, or Google?

No. PersonalOS is an independent open-source project. It uses these companies' models via API (through OpenRouter) but has no affiliation with any of them.

Models & Costs
Which AI models does PersonalOS support?

Any model available on OpenRouter — including Claude, GPT-4, Gemini, Mistral, Llama, Perplexity, and more. You configure which model each agent uses in its config.yaml.

The default setup routes lightweight tasks to Gemini Flash and heavy reasoning to Claude Sonnet/Opus.

What happens when a new model comes out?

Change one line in the agent's config file. Your memory, workflows, and all past outcomes stay exactly as they were — nothing needs to be migrated or re-trained.

The weekly model watcher also sends you a Telegram report comparing current benchmarks so you know when a swap is worth it.

How much does it cost to run?

Roughly $30–60/month for personal use, $60–150/month if you're running business agents heavily.

The biggest cost is API usage. PersonalOS routes cheap tasks (summaries, email drafts) to fast, inexpensive models and only uses powerful models for complex reasoning — which cuts costs 5–10x versus using one model for everything.

VPS cost is typically $6–10/month (Hetzner or Hostinger).

Can I run it with a local model like Ollama?

Ollama support is on the roadmap. Currently PersonalOS routes through OpenRouter, which requires an API key. Local model support will be added in a future release.

Privacy & Data
Where does my data live?

On your VPS. The memory layer (PostgreSQL) runs on your own server. PersonalOS doesn't send your memory or workflows to any third party — only the specific content of individual API calls goes to your chosen model provider.

Is it safe to connect my Gmail and calendar?

Credentials are stored locally on your server as environment variables — they're never sent to PersonalOS developers or any external service beyond the Google API itself (which you authenticate directly via OAuth).

You can revoke access at any time from your Google account settings.

What if my VPS goes down?

Your data stays in the PostgreSQL database. The update.sh script handles restarts, and you can set up automatic backups with standard PostgreSQL tooling (pg_dump to S3 or any cloud storage).

Agents & Customisation
Can I add my own agents?

Yes. Copy an existing agent folder, edit the soul.md (identity) and config.yaml (model, tools, schedule), then register it with personalos agent register my-agent. See the Creating Agents guide for the full walkthrough.

Which persona should I start with?

Pick the one closest to your primary use case:

Solo Founder — running a business, need leverage on ops and content.
Freelancer — client work, invoicing, project tracking.
Student — research, deadlines, knowledge management.
E-commerce — store ops, ads, inventory, customer support.

You can switch or customise at any time — personas are just YAML config files.

Can I use PersonalOS from my phone?

Yes — Telegram is the primary mobile interface. You can send tasks, receive briefings, approve actions, and get agent replies entirely through Telegram. A dedicated iOS/Android app is on the roadmap.

How does the self-improve loop actually work?

Every completed task is scored (0–1) and stored in your database. Before starting a new task of the same type, the agent retrieves the highest-scoring past workflow and uses it as a template. Over time, your agents build a personal library of what works specifically for you. See the Self-Improve Loop guide for details.
