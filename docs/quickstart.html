Quickstart

Deploy PersonalOS on your own VPS in about 30 minutes.

What you need

  • A VPS with Ubuntu 22.04+ (2 vCPU, 4GB RAM minimum)
  • An OpenRouter API key (~$20 starting credit)
  • A Telegram account (for notifications and control)

Steps

1

Clone the repo

git clone https://github.com/krishnatejaganesh/personalos
cd personalos
2

Configure your environment

cp .env.example .env
nano .env

Add your OpenRouter API key and Telegram bot token. Every setting is documented in the file.

3

Run the setup wizard

./scripts/setup.sh

The wizard asks 5 questions, installs dependencies, initialises the database, and starts all agents.

4

Say hello on Telegram

Open your Telegram bot and send: "What should I focus on today?"

Your Chief of Staff agent will read your calendar, check emails, and give you your top 3 priorities.
