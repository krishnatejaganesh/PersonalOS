Quickstart

Get PersonalOS running on your machine or VPS in about 30 minutes.

What you need

  • A machine to run it on — your Mac/Linux laptop, or a VPS (Hetzner €6/mo, Hostinger $7/mo)
  • Docker Desktop (Mac/Windows) or Docker Engine (Linux)
  • An OpenRouter API key — ~$20 starting credit
  • A Telegram bot — takes 2 minutes, see Telegram Setup

Before you run setup — create your Telegram bot

PersonalOS talks to you through Telegram. You need a bot token and your user ID before running the setup wizard.

1

Create your bot

Open Telegram and message @BotFather. Send /newbot, pick a display name and username (must end in bot). BotFather replies with a token like:

7123456789:AAF_abc123XYZexampleTokenHere

Copy it — you'll paste it into the setup wizard.

2

Get your user ID

Message @userinfobot on Telegram. It replies instantly with your numeric ID (e.g. 123456789). Copy that too.

Full walkthrough with troubleshooting: Telegram Setup guide →

Deploy

3

Clone and run setup

git clone https://github.com/krishnatejaganesh/PersonalOS
cd PersonalOS
./scripts/setup.sh

The wizard asks for your name, timezone, OpenRouter key, Telegram token, and user ID — then starts everything automatically.

4

Send your bot a message

Find your bot in Telegram and send: "Hello, are you there?"

It should reply within a few seconds. You're running.

5

Tell it about yourself

The more context you give, the more useful PersonalOS is from day one. Paste this into the bot:

Remember these things about me permanently:

My name is [your name].
My work: [describe what you do].
My priorities: [e.g. revenue, product, family].
Always ask before sending emails or taking any action.
