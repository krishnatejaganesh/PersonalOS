Self-Improve Loop

How PersonalOS gets smarter every day without changing the model.

How it works

Every completed task is scored and stored. Before starting a new task, agents retrieve the highest-scoring workflow for that task type and use it as a starting point.

What gets stored

-- After every task completes
INSERT INTO workflow_outcomes (task_type, steps, outcome, score)
VALUES ('seo_article', '[...]', 'published, 2k views in 24h', 0.92);

What gets retrieved

-- Before every task starts
SELECT steps FROM workflow_outcomes
WHERE task_type = $1 AND score > 0.75
ORDER BY score DESC LIMIT 1;

Scoring

Scores are set automatically based on task outcomes (did the PR merge? did the article get traffic?) or manually via Telegram:

"Rate that last task 0.9 — the article performed really well"

Over time, your agents build a personal library of what actually works for you — independent of which model is running underneath.
