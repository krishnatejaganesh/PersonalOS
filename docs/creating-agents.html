Creating Agents

Build a specialised AI worker with its own identity, tools, model, and schedule.

1. Copy an existing agent

cp -r agents/developer agents/my-agent

2. Edit the soul

soul.md defines the agent's identity, goals, and constraints. Be specific — the more precise the soul, the more consistent the behaviour.

nano agents/my-agent/soul.md

3. Edit the config

config.yaml sets the model, tools, and cron schedule.

model: claude-sonnet-4-6
tools:
  - gmail
  - github
schedule: "0 9 * * 1-5"  # 9am weekdays

4. Register the agent

Add your agent to the router so tasks can be routed to it:

personalos agent register my-agent

That's it. Your agent will appear in the Telegram menu and accept tasks via natural language.
